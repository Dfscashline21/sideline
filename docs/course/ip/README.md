## This track runs in parallel

IP isn't a module you do after the others. It's a steady rhythm of small
practice sessions **alongside** the build, so you're sharp when the
portfolio goes live. Budget about 3 to 4 hours a week.

## Privacy

The epic's artifact is **private notes**: STAR stories, the practice log
and mock results. Keep them in a private notes app or private repo. The
public repo can hold SQL practice solutions on Sideline data (in `sql/`)
and modelling exercises in invented domains (IP.4), but nothing about
your employer, and no mock recordings.

Suggested private layout:

```
interview-prep/              (private)
├── star-stories.md          # IP.1, plus each module's STAR ticket
├── sql-log.md               # IP.2
├── design-log.md            # IP.3 (recordings linked, stored privately)
├── modeling-log.md          # IP.4 (or public, see the lab)
├── cold-questions.md        # IP.5
└── mock-loops.md            # IP.6
```

## Know these before you start

| Fact | Why it matters |
|---|---|
| Spacing beats cramming | Three 20-minute SQL sessions a week beat one hour on Sunday |
| Timed practice is different practice | Always use a timer; interviews are time-boxed |
| Logs show you patterns | After ten entries, your log tells you which pattern or phase you keep failing |
| Saying it out loud is a separate skill | Record design and behavioural practice; silent practice overstates how ready you are |
