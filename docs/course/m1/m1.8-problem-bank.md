# M1.8 · Solve 20 more problems for the `sql/` folder

> **Ticket:** [#33](https://github.com/Dfscashline21/sideline/issues/33) ·
> **Mode:** hand · **Time:** 10 to 15 hours over the week (30 to 45 min each) ·
> **Needs:** M1.3 to M1.7

## Why this matters

Labs teach a pattern once. Interviews need you to **recognise** the
pattern in an unfamiliar question within a minute, and that only comes
from volume. This ticket is reps.

The rule from the ticket: **use an agent only to check answers after you
finish.** Not for hints, not to "get started".

## What you'll produce

- 20 more `.sql` files in `sql/problems/`, for **25 in total**.
  (M1.3 to M1.7 gave you five: four problems plus M1.7's optimised version.)
- Every file starts with the standard header naming the pattern.
- `sql/README.md` listing all 25, one line each.

## How to work each problem

1. **Read the problem and name the pattern before writing anything.**
   Write it in the header first. Practising that recognition is the main
   point of this ticket.
2. Set a 30-minute timer. Solve it.
3. Verify it: a hand-checked row, a known fact, or an invariant
   (e.g. wins + losses = games played).
4. *Then* ask an agent: "Here's a problem and my solution. Is it correct?
   Any edge case I missed? Don't rewrite it." Fix what's real.
5. If you blew the timer, mark the file `-- Revisit: yes` and redo it
   from scratch in three days.

Header for every file:

```sql
-- Problem:  <one sentence>
-- Pattern:  <pattern name>
-- Tables:   <tables>
-- Verified: <how you know it's right>
-- Revisit:  no
```
